
## Agentic Loop


1. Your Prompt
2. Model
	1. Gather Context
	2. Take Action
	3. Verify Results, if not good enough return to step 1 of Model


## Tools

Tools - are code functions that an agent is aware of an can invoke to complete their tasks.


Claude Code Built-in tools fall into five categories:
- File Operations - read files, edit code, create new files, rename and reorganise
- Search Find - searches file by pattern, search context with regex, explore codebases
- Execution Run - executes shell commands, start servers, run tests, use git
- Web Search - searches the web, fetch documentation, look up error messages
- Code Intelligence - looks at type errors and warnings after edits, jump to definitions


## Stop Reason

Stop Reason - is the reason why the Claude Agent has stopped executing its loop.

Stop reason will be of two different values:
1. Tool Use
2. End Turn

The JSON data returned from a request to the agent will have "stop_reason"
