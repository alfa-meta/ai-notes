
Claude Code works in two main modes: plan mode and direct execution.
Th exam tests whether you can pick the right one for a given task.
it's not a matter of taste - there are clear criteria for when each mode fits.

## Plan Mode: When to Use It

Plan mode is for complex tasks where you need to explore the codebase, evaluate multiple approaches, and design a strategy before making changes.
Use plan mode when:
- Large-scale changes are involved.
	- Restructuring a monolith into microservices, reorganising a module system, or refactoring a core abstraction all require understanding the existing structure before changing it.
- Multiple valid approaches exist.
	- When there are different ways to solve the problem, you need to evaluate them before committing
- Architectural decisions are required.
- Multi-file modifications are needed.
- Codebase exploration is necessary
